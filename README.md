# caldeiralabs.com

Site estático da Caldeira Labs (BasketStats e Voyage), publicado no Cloudflare Pages.
Sem passo de compilação: o Cloudflare serve esta pasta tal como está.

- `index.html` — página inicial
- `basketstats/` — app e guia; `basketstats/privacy/` — política de privacidade; `basketstats/manuais/` — PDFs gerados em C:SERSCALDEIRABASKETSTATS-MANUAIS (NODE BUILD.JS)
- `voyage/` — app; `voyage/privacy/` — política de privacidade
- `assets/` — estilos, mudança de língua (PT/ES/EN) e imagens
